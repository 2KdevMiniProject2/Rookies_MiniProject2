# 📱 [루키즈 미니프로젝트 2] 04. 화면 설계서

---

## 1. 개요 및 설계 도구

* **설계 도구**: Figma (피그마 와이어프레임 기반)
* **디자인 컨셉**: 모던하고 가독성이 뛰어난 카드 기반 레이아웃 (반응형 웹 지원)
* **목표**: 손님과 사장님이 직관적으로 주문/관리할 수 있는 최소한의 동선 제공

---

## 2. 사이트맵 (Sitemap)

```
[루키즈 오더 서비스]
├── 🟢 파트 A
│   ├── /login                     (로그인 및 회원가입 페이지)
│   ├── /                          (메인 홈: 가게 목록 & 카테고리 필터)
│   └── /owner/store/edit          (사장님 매장 등록 및 정보 수정)
├── 🟡 파트 B
│   ├── /stores/:storeId           (가게 상세 & 메뉴판 & 장바구니 바)
│   ├── /checkout                  (주문서 작성 & 픽업 시간 선택)
│   └── /owner/menus               (사장님 메뉴 등록 & 품절 관리)
└── 🔴 파트 C
    ├── /owner/dashboard           (사장님 실시간 주문 접수 & 당일 매출)
    └── /orders/:orderId/status    (손님용 실시간 주문 진행 상태 확인)
```

## 3. 사용자 동선 및 UI 플로우 (UI Flow)

### 3.1 👨‍💼 사장님 플로우 (Owner Flow)
```
[로그인 (사장님)] 
       │
       ▼
[사장님 마이페이지/가게 관리] ─── (가게 정보 등록/수정)
       │
       ├─── [메뉴 관리] ─── (신규 메뉴 등록 / 실시간 품절 스위치 On/Off)
       │
       ▼
[주문 접수 대시보드] ─── (실시간 주문 인입 🔔)
       │
       ├─── [주문 수락] 클릭 ➔ 상태: [조리중 ⏳]
       │
       ├─── [조리 완료] 클릭 ➔ 상태: [픽업 대기/완료 🛍️]
       │
       ▼
[오늘의 매출 요약 카드] ─── (오늘 완료된 총 주문 건수 및 총 매출액 확인)
```

### 3.2 🙋 손님 플로우 (Customer Flow)
```
[메인 홈 접속] 
       │
       ├─── (카테고리 필터 클릭: 전체 / 카페 / 베이커리 / 한식)
       │
       ▼
[가게 카드 선택 (클릭)]
       │
       ▼
[가게 상세 / 메뉴판] ─── (메뉴 구경 및 `+ 담기` 클릭)
       │
       ├─── (하단 플로팅 장바구니 바: 총 수량, 총 금액 실시간 표시)
       │
       ▼
[주문하기 버튼 클릭]
       │
       ▼
[주문서 작성 & 픽업 시간 선택] ─── (픽업 희망 시간 및 요청사항 기입)
       │
       ▼
[주문 완료 버튼] ─── (주문서 생성: 5001번)
       │
       ▼
[실시간 내 주문 상태 확인] ─── (접수대기 ➔ 조리중 ➔ 조리완료 프로그레스 바 실시간 확인)
```
