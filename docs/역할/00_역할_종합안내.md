## 2. 공통 협업 원칙 (반드시 숙지!)

1. **저장소 브랜치 분리 전략**:
   * 백엔드는 `backend_main`, 프론트엔드는 `frontend_main`을 기반으로 작업합니다.
   * 프론트엔드 폴더에서 백엔드 브랜치로 checkout하지 않도록 주의합니다!
2. **독립 개발 치트키 (Dummy Data)**:
   * 다른 파트의 작업이 끝날 때까지 기다리지 마세요.
   * `가게 1번 (루키즈 베이커리)`과 `주문 5001번 (바닐라라떼 2잔)` 더미 데이터를 바탕으로 즉시 자기 파트 화면과 로직을 개발합니다.
3. **API 연동 규격 준수**:
   * [03_REST_API_설계서.md](file:///c:/Users/user/Documents/SKDev06/Project/%EB%AF%B8%EB%8B%88%ED%94%84%EB%A1%9C%EC%A0%9D%ED%8A%B802/%EA%B0%9C%EC%9A%94/03_REST_API_%EC%84%A4%EA%B3%84%EC%84%9C.md)에 정의된 경로 및 JSON 필드명을 그대로 사용해야 추후 병합 시 오류가 발생하지 않습니다.
