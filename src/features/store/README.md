# store
메인 홈(가게 목록 = "매장 찾기") 화면을 담당하는 폴더입니다. 매장 목록은 `storeApi.js`를 통해 불러오고, 헤더의 로그인 상태는 `src/store/authStore.js`(Zustand)에서 읽습니다.

## ⚠️ 현재 데이터 연동 상태

- **매장 목록은 더미 데이터로 동작 중입니다.** `storeApi.js`의 `USE_DUMMY = true` 스위치 때문에 실제 API(`GET /api/stores`)를 호출하지 않고, `dummyStores.js`의 매장 30개를 0.4초 뒤에 돌려줍니다. (로딩 화면 확인용 지연)
- **실제 백엔드와는 아직 연결하지 않았습니다.** `USE_DUMMY`를 `false`로만 바꾸면 응답 형식이 맞지 않아 화면이 깨집니다. (TODO 참고)
- 검색·카테고리 필터·페이지네이션은 **받아온 전체 목록을 화면에서 처리**합니다. 백엔드가 정렬·페이지·검색어 파라미터를 지원하지 않기 때문입니다.

## 메인 홈 화면 — `StoreListPage.jsx` (`/`)

### 헤더 (스크롤해도 상단 고정)
| 위치 | 내용 |
|---|---|
| 왼쪽 | 로고 "오더메이트" (클릭 시 `/`) |
| 가운데 | 매장명 검색창 (최대 640px, 항상 헤더 정중앙) |
| 오른쪽 | 로그인 전: "로그인" 버튼 → `/login` / 로그인 후: "OOO님" · 마이페이지 아이콘 · "로그아웃" 버튼 |

- 마이페이지 아이콘은 아직 경로 연결 전 — 클릭 시 콘솔 로그만 출력
- "로그아웃"은 `authStore.logout()`을 호출하고 메인 홈에 그대로 머묾
- 이 헤더는 메인 홈 전용입니다 (별도 공용 헤더 컴포넌트 아님)

### 본문
- **안내 배너**: "지금 주문 가능한 가게" / "가까운 가게에서 미리 주문하고 바로 픽업하세요."
- **카테고리 탭**: 전체 / 카페/디저트 / 한식 / 양식 / 베이커리 / 기타
- **결과 개수**: "가게 N곳" (필터·검색 적용 후 개수)
- **가게 카드 그리드**: 카드 최소 폭 300px, 화면 폭에 따라 4열(1324px~) · 3열 · 2열(684~1003px) · 1열(~683px)
- **페이지네이션**: 목록 아래 "이전 · 페이지 번호 · 다음" 버튼

### 검색 · 카테고리 필터 · 페이지네이션 (구현 완료)
| 기능 | 동작 |
|---|---|
| 카테고리 필터 | 선택한 카테고리와 `store.category`가 정확히 같은 매장만 표시 (`전체`는 모두 표시) |
| 검색 | 매장명 부분 일치, 대소문자 무시, 앞뒤 공백 무시 (카테고리 필터와 함께 적용) |
| 페이지네이션 | 필터 결과를 **페이지당 8개**(`PAGE_SIZE`)씩 잘라서 표시 (`slice`). 더미 30개 기준 4페이지(8·8·8·6) |
| 1페이지로 돌아가는 경우 | 카테고리 변경, 검색어 변경, "전체 가게 보기" 클릭 |
| 페이지 이동 시 | 화면 맨 위로 부드럽게 스크롤 |
| 버튼 표시 | 결과가 1페이지 이하이면 페이지 버튼을 숨김. 첫 페이지에서 "이전", 마지막 페이지에서 "다음"은 비활성화 |

### 상태 처리
| 상태 | 표시 |
|---|---|
| 로딩 중 | 회색 카드 틀(스켈레톤) 6개 + 반짝임 효과 |
| 불러오기 실패 | "가게 목록을 불러오지 못했습니다." + "다시 시도" 버튼 |
| 결과 없음 | "조건에 맞는 가게가 없어요" + "전체 가게 보기" 버튼 (검색어·카테고리 초기화) |

### 이동
- 가게 카드(또는 "가게 상세보기" 버튼) 클릭 → `/stores/{storeId}` (파트 B 매장 상세 화면)

## 가게 카드 — `StoreCard.jsx`

### Props
| Prop | 타입 | 용도 |
|---|---|---|
| `store.id` | `number` | 클릭 시 `onClick`에 전달 |
| `store.name` | `string` | 가게명 (1줄, 넘치면 `...`) |
| `store.category` | `string` | 카테고리 뱃지 |
| `store.address` | `string` | 주소 (핀 아이콘) |
| `store.openTime` / `store.closeTime` | `string` (`'HH:mm'`) | 영업시간 표시 + 영업 상태 계산 |
| `store.imageUrl` | `string?` | 대표 이미지 |
| `store.description` | `string?` | 한 줄 소개 — 있을 때만 표시 |
| `store.rating` | `number?` | 별점 — 있을 때만 표시 |
| `onClick` | `(storeId: number) => void` | 카드 또는 "가게 상세보기" 버튼 클릭 시 호출 |

### 카드 구성
- **이미지**: 항상 3:2 비율. `imageUrl`이 없거나(`null`) 로딩에 실패하면 같은 비율의 회색 박스 + 이미지 아이콘으로 대체
- **영업 상태 뱃지**: 현재 시각과 영업시간을 비교해 "주문 가능" / "준비 중" 표시 (마감이 자정을 넘기는 경우도 처리)
- 가게명 + ★별점 → 카테고리 뱃지 + 한 줄 소개 → 영업시간(시계 아이콘) → 주소(핀 아이콘) → "가게 상세보기" 버튼
- 모든 텍스트 줄을 1줄로 고정해 가게명 길이·소개 유무·이미지 유무와 관계없이 **카드 높이가 항상 같음**

## 카테고리 필터 — `CategoryFilter.jsx`

| Prop | 타입 | 용도 |
|---|---|---|
| `categories` | `string[]` | 표시할 카테고리 목록 (`'전체'` 포함) |
| `selectedCategory` | `string` | 현재 선택된 카테고리 — 일치하는 칩을 포인트 컬러로 표시 |
| `onSelectCategory` | `(category: string) => void` | 칩 클릭 시 호출 |

- 선택 상태는 부모(`StoreListPage`)가 관리
- 칩이 화면보다 길면 가로 스크롤 (스크롤바는 숨김)

## 데이터 — `storeApi.js` · `dummyStores.js`

### `getStores()`
- `USE_DUMMY = true` → 0.4초 기다린 뒤 `DUMMY_STORES` 반환
- `USE_DUMMY = false` → `GET /api/stores` 호출 후 `res.data.data` 반환 (⚠️ 백엔드 응답 형식과 불일치, TODO 참고)

### 더미 매장 30개
- 필드: `id`, `name`, `category`, `address`, `storePhone`, `openTime`, `closeTime`, `description`, `imageUrl`, `rating`, `reviewCount`
- **`imageUrl`은 30개 모두 `null`** — 이미지가 없을 때 카드의 대체 박스 처리를 확인하기 위함
- 카테고리 분포: 카페/디저트 6 · 한식 7 · 양식 6 · 베이커리 6 · 기타 5
- id 1은 1차 기획 문서의 `dummy_data.sql` 1번 매장 값을 옮긴 것, id 2~30은 필터·페이지네이션 테스트용 가상 매장
- 테스트용 특수 매장: id 12(가게명·주소가 아주 긴 경우 말줄임 확인), id 19(18:00~02:00, 자정을 넘기는 영업시간 확인)

## 스타일

### 디자인 방향
- **무채색(흰색·회색·검정) + 포인트 컬러 하나**로 구성 (로그인·회원가입 화면과 같은 방식)
- 팀 공통 루트 변수(`src/index.css`의 `--accent`, `--bg` 등)는 쓰지 않고, `StoreListPage.module.css`의 `.page`에 정의한 **로컬 변수 `--home-*`**만 사용
- `StoreCard.module.css`, `CategoryFilter.module.css`도 이 `--home-*` 변수를 사용 → 두 컴포넌트는 메인 홈 페이지 안에서 렌더링된다는 전제
- 루트 파일(`index.css`, `App.jsx`, `App.css`)은 수정하지 않음

### 포인트 컬러
| 변수 | 값 | 쓰는 곳 |
|---|---|---|
| `--home-accent` | `#ed5821` (색조 16° · 채도 85% · 명도 53%) | 선택된 카테고리 칩, 현재 페이지 번호, "가게 상세보기" 버튼, 헤더 "로그인"/"로그아웃" 버튼 |
| `--home-on-accent` | `#ffffff` | 위 요소들의 글자, 배너 글자 |

- `AuthForm.module.css`의 `--auth-accent`와 같은 값
- 포인트 컬러 버튼은 마우스를 올리면 살짝 어두워짐(`brightness(0.92)`)
- 흰 글자와의 대비는 3.49:1 (큰 글자 기준 3:1은 넘고, 본문 기준 4.5:1은 미달)

### 안내 배너 그라데이션
| 변수 | 값 | 흰 글자 대비 |
|---|---|---|
| `--home-hero-from` | `var(--home-accent)` = `#ed5821` (왼쪽 위) | 3.49:1 |
| `--home-hero-to` | `#ff8f66` (오른쪽 아래, 색조 16° · 채도 100% · 명도 70%) | 2.24:1 |

- 135° 대각선 그라데이션으로, 왼쪽은 진하고 오른쪽으로 갈수록 밝아짐
- 제목·설명 글자는 흰색. 글자는 배너 왼쪽(진한 쪽)에 놓임
- `--home-hero-from`은 `--home-accent`를 따라가므로 포인트 컬러를 바꾸면 배너 시작 색도 같이 바뀜 (끝 색은 따로 지정)

### 시그널 컬러 (의미 전달용으로 그대로 유지)
| 색 | 쓰는 곳 |
|---|---|
| 초록 `rgba(34, 160, 90, 0.9)` | 카드 "주문 가능" 뱃지 |
| 회색 `rgba(60, 60, 70, 0.75)` | 카드 "준비 중" 뱃지 |
| 노랑 `#f5a524` | 카드 별점 ★ |

### 그 밖의 요소
| 요소 | 스타일 |
|---|---|
| 선택 안 된 카테고리 칩 | 흰 배경 + 회색 테두리 |
| 페이지 번호 (현재 페이지 제외) · 이전/다음 | 흰 배경 + 회색 테두리, 비활성화 시 흐리게 |
| 마이페이지 아이콘 | 투명 배경 + 회색 원형 테두리 |
| 카테고리 뱃지 (카드 안) | 연회색 배경 + 검정 글자 |
| 검색창 | 연회색 면 `#f2f2f2`, 포커스 시 흰 배경 + 진한 테두리 |

### 다크모드
- **현재 OS 설정과 관계없이 라이트 모드로 고정**
- 다크모드용 변수 값은 삭제하지 않고 `StoreListPage.module.css`의 `[비활성] 다크 모드` **주석 블록으로 보관** → 다시 쓰려면 주석을 풀고, 같은 파일의 `color-scheme: light` 한 줄도 지워야 함
- 라이트 고정을 위해 이 파일 안에서 막은 것
  - 루트 `color-scheme: light dark` 때문에 스크롤바·검색창 지우기(×) 버튼이 어둡게 그려지는 문제 → 메인 홈이 떠 있을 때만 `color-scheme: light`
  - 루트의 `h1` 색 규칙·글자색 상속 → 제목과 `.page`에 글자색 직접 지정
  - 버튼·링크의 브라우저 기본 파란 포커스 테두리 → 무채색 테두리로 통일

### 레이아웃
- 최상위 `.page`는 `width: 100vw; margin-left: calc(-50vw + 50%)`로 공용 `#root`(최대 1126px) 박스를 벗어나 화면 전체 폭 사용. 가로 스크롤은 `:global(html):has(.page)`에 `overflow-x: clip`을 넣어 메인 홈이 떠 있을 때만 막음
- 콘텐츠 최대 너비 1400px(`--content-max`), 좌우 여백 32px(`--gutter`)
- 화면 너비 640px 이하: 좌우 여백 16px, 헤더 2줄(1줄: 로고 · 메뉴 / 2줄: 검색창 전체 폭), "OOO님" 숨김, 배너 제목 28px → 22px
